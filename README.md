# TriLex | دیکشنری کلاس آلمانی

صفحه دانلود برنامه **TriLex** برای دانش‌آموزان کلاس آلمانی.

- **اندروید:** دانلود فایل APK از GitHub Releases
- **آیفون:** نسخه وب دیکشنری، قابل افزودن به صفحه اصلی گوشی

نسخه وب: https://deutsch-tech.github.io/Deutsches_W-rterbuch/

---

## فایل‌های ریپو

| فایل | توضیح |
|------|-------|
| `index.html` | صفحه دانلود |
| `README.md` | همین راهنما |

فایل APK در بخش **Releases** نگهداری می‌شود:
https://github.com/Hajmehrad/TriLex/releases/download/v1.4/TriLex.apk

---

## راه‌اندازی

1. `index.html` و `README.md` را در ریپوی `TriLex` آپلود کنید.
2. **Settings ← Pages ← Deploy from a branch ← main / (root)** را انتخاب و ذخیره کنید.
3. بعد از حدود یک دقیقه آدرس صفحه آماده است: `https://Hajmehrad.github.io/TriLex/`

---

## به‌روزرسانی برنامه

1. یک Release جدید بسازید (مثلاً `v1.5`) و APK جدید را آپلود کنید.
2. در `index.html` عبارت `v1.4` را در لینک دانلود با نسخه جدید عوض کنید.

---

## حریم خصوصی

- صفحه `noindex` است و در گوگل نشان داده نمی‌شود.
- هر کسی آدرس را داشته باشد می‌تواند وارد شود، پس آدرس را فقط در گروه کلاس بفرستید.
- ریپوی خصوصی با Pages معمولاً به پلن پولی GitHub نیاز دارد. لینک Release هم باید عمومی باشد تا دانش‌آموزان بتوانند دانلود کنند.

---

## نصب برای دانش‌آموزان

**اندروید:** دانلود را بزنید، فایل را باز کنید، نصب از این منبع را فعال کنید و نصب را بزنید.

**آیفون:** لینک نسخه وب را در Safari باز کنید، Share و بعد Add to Home Screen را بزنید.

APK فقط روی اندروید کار می‌کند.
